## What's new

- **Settings window** with General, Appearance, Island, Widgets, Integrations, Notifications,
  Privacy and About pages. Typed, versioned `settings.json`, validated in Rust, applied live.
- **Appearance:** Midnight, Graphite and Frost themes; six accents; background opacity; corner
  presets; full/subtle animation; reduced-motion override.
- **Placement:** display selection with fallback, top left/center/right, offset, top margin,
  Alt+drag, three size presets.
- **Widgets:** enable, disable and reorder Now Playing, Calendar, Activity, System and Sound.
- **Interaction:** open on hover/click, delays, pin on click, auto-collapse for pinned dashboards.
- **Shortcut:** configurable, validated, never overrides another app; conflicts reported.
- **Launch at startup** (per-user, opt-in), start hidden, **single instance**, **tray menu**
  (Show/Hide, Settings, Quiet mode, Launch at startup, About, Quit).
- **Fullscreen apps** hide the island on their monitor; monitor changes re-place it within 2 s.
- **Notifications:** per-source and per-outcome peeks, duration, retention (1–30 days), and a
  per-source peek rate limit (4 per minute; attention requests exempt).
- **Integrations page:** Claude Code status, last event, install/reinstall/remove,
  troubleshooting; developer receiver status and a real test event; Windows capability overview.
- **Privacy & diagnostics:** local bounded log, detailed-logging switch, copyable diagnostic
  summary, storage overview, clear history, reset settings.
- **Installer:** per-user NSIS; uninstall removes the startup entry and Islandy's Claude Code
  hooks (with a backup), never during updates.

## Changed

- `ISLANDY_TOGGLE_SHORTCUT` is no longer read; the shortcut is a setting.
- The tray's "Preview peek (demo)" item is gone (use Settings › Integrations › Send test).
