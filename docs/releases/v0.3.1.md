# Islandy 0.3.1

Claude on the island, and automatic updates that actually arrive.

## New

- **Claude's logo on the island.** The orange Claude mark sits between the clock and the music
  bars. It breathes slowly while Claude is idle, turns while Claude works and pulses amber when
  Claude needs you. It holds still when Windows animations are off, and hides when the Claude
  source is off.
- **Click the logo for Claude's status.** It opens the Claude panel directly: sessions,
  permission requests (Allow once / Deny) and the last 24 hours. The rest of the island still
  opens the dashboard.

## Fixed

- **Automatic updates.** Every earlier version failed to find updates because the project's
  repository was private, and GitHub doesn't let anyone download a private repository's release
  files without signing in. The repository is now public, and a Windows test confirmed that an
  installed 0.2.1 updates itself to the latest release. Update errors now say what failed.
- The Claude panel's 24-hour totals no longer spill out of the panel while a permission request
  is open.

## Upgrading

Islandy 0.2.1 and 0.3.0 install this update automatically: they check about 45 seconds after
starting and every 6 hours, and install once you've been away for 4 minutes. You can also use
**Settings › About › Check for updates**.
