# Islandy 0.3.2

A notification sound.

## New

- **Notification sound.** A soft two-note chime plays when something new lands on the island:
  Claude finished or needs you, a build or test result, a system alert, an update. The sound is
  synthesized by Islandy itself. It plays with activity peeks only (not track changes), so quiet
  mode and the per-source peek switches apply, and it follows the Windows "System sounds"
  volume.
- **Settings › Notifications › Sound**: turn it off, pick Soft / Normal / Loud (each plays a
  preview), or press **Play**.

## Upgrading

Islandy 0.2.1 and later install this update automatically. The sound is on after updating; turn
it off in Settings › Notifications if you prefer silence.
