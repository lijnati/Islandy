# Islandy 0.2.1

Claude Desktop activity on the island, the official Claude mark, and a media-button fix.

## New

- **Claude Desktop activity.** While Claude Desktop (the chat app) writes a reply, the island
  shows "Claude Desktop · Working", and a "Claude finished responding" peek appears when it's
  done. Windows only. Detection uses Windows UI Automation and checks only whether Claude's
  "Stop response" button is on screen; no chat content is read. Claude Code in Claude Desktop's
  Code tab uses the existing hooks: install them in **Settings › Integrations**, then start a
  new session.

## Changed

- The island shows the official Claude mark in Claude's brand colour, turning and breathing
  while Claude works (still respecting reduced motion).

## Fixed

- The play/pause button didn't pause YouTube and other browser media (Chrome and Edge ignore
  the "toggle" command); Islandy now sends explicit Play and Pause.

## Upgrading

Islandy 0.2.0 installs this update automatically through the updater once it is released; no
manual download is needed. Settings, history and hooks are kept.
