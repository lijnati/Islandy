# Islandy 0.3.0

Answer Claude Code from the island, see how your day with Claude went, and a smoother first
launch.

## New

- **Answer permission requests on the island** (opt-in). Turn on **Settings › Integrations ›
  Answer permission requests on the island**, then click **Repair** on the hooks once. When
  Claude Code asks for permission, the Claude panel shows what it wants to do (the command,
  file, URL or tool) with **Allow once**, **Deny** and **Answer in Claude Code**. Claude Code
  waits up to 30 seconds, then asks in its own prompt as before. Allow is offered only when the
  whole request fits on one line, and Islandy never answers by itself.
- **Claude usage glance.** Turns, time Claude spent working and how often it needed you over
  the last 24 hours, plus per-session counts. Computed from hook timing in memory only.
- **Use my location** for the weather: one click reads your position from Windows location
  services, rounded to about 1 km, instead of typing a city.
- **Welcome page** on first launch (fresh installs) pointing to the Claude Code hooks, the
  weather place and the island shortcut. Reopen it from **Settings › About**.

## Changed

- Claude Desktop detection now recognises the stop button case-insensitively and in more UI
  languages. The non-English names are best-effort and not yet verified.
- Every push is now tested on Windows in CI, including a start-up smoke test.

## Not yet verified on real Windows

The permission answers (against a live Claude Code session), the Windows location read and the
non-English Claude Desktop names have automated tests only. See
[known limitations](../known-limitations.md).

## Upgrading

Islandy 0.2.x installs this update automatically once it is released. Settings, history and
hooks are kept; the hooks show "Hooks need repair" until you click **Repair**, which is needed
only for answering permission requests.
