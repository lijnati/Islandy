# Islandy 0.2.0

Islandy now keeps itself up to date, and the dashboard gains a weather widget.

## New

- **Automatic updates.** Islandy checks this project's GitHub Releases shortly after it starts
  and every 6 hours. A new version is downloaded in the background, its signature is verified,
  and it installs while you're away from the PC (Islandy restarts in a few seconds). Install at
  once with **Restart to update** in the tray or **Settings › About**, where you can also turn
  checking or automatic installation off.
- **Weather widget.** Current temperature and conditions, feels-like, humidity, wind, today's
  high and low and the next three days, for a place you pick in **Settings › Widgets ›
  Weather** (°C or °F). Forecasts come from Open-Meteo: no account, no key, only the place's
  rounded coordinates are sent, and only while the widget is on screen.

## Fixed

- The settings window could open black and refuse to close on Windows when opened from the
  dashboard's settings button.

## Upgrading from 0.1.0-rc.1

The release candidate has no updater: install 0.2.0 over it once. Settings, history, Claude Code
hooks and launch at startup are kept. From 0.2.0 on, updates install themselves.

## Notes

- The installer is not code-signed yet, so Windows SmartScreen may warn on first run
  (**More info → Run anyway**).
- The weather widget is off by default; turn it on in Settings › Widgets (choosing a place turns
  it on).
